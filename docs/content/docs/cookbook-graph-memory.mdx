# Cookbook: Note Memory

`bricks-memory` keeps long-term memory as short notes. Each note is a Markdown file, and a generated `MEMORY.md` lists them. There is no database and no feature flag.

<Callout type="info">
The Grafeo graph store, `StructuredMemory` and the `structured` feature were removed. Nothing is extracted from conversations: a note is saved when the agent or the application writes it.
</Callout>

## Opening the stores

A scope is one directory with one store. Use one store for the project and one for the global memory:

```rust
use std::sync::Arc;
use bricks_memory::{FileNoteStore, ScopedFileMemory};

let project = Arc::new(FileNoteStore::new("./.bricks/memory"));
let global = Arc::new(FileNoteStore::new(home.join(".bricks/memory/global")));

let memory = ScopedFileMemory::new(Some(project), Some(global), Some("my-project".into()));
```

`FileNoteStore::new` does not create the directory. The first write does.

## Writing and reading notes

`LongTermMemory` takes a `MemoryScope` (`Project` or `Global`) for each call:

```rust
use bricks_memory::{LongTermMemory, MemoryScope};

let id = memory
    .write_note(MemoryScope::Project, None, "Auth uses RS256 JWTs stored in HttpOnly cookies.")
    .await?;

memory
    .update_note(MemoryScope::Project, &id, "Auth uses RS256 JWTs in HttpOnly cookies, rotated daily.")
    .await?;

let page = memory.list_notes(MemoryScope::Project, Some("jwt"), 0, 20).await?;
for note in page.notes {
    println!("[{}] {}", note.id, note.text);
}

memory.delete_note(MemoryScope::Project, &id).await?;
```

A note holds at most 280 characters. Writing the same text twice returns the existing note.

## Giving the notes to an agent

Attach the memory to the agent. Each run then adds the index of both scopes to the system prompt, within the token budget:

```rust
use std::sync::Arc;
use bricks::Agent;

let agent = Agent::builder()
    .provider(provider)
    .tools(bricks::tools::coding())
    .long_term_memory(Arc::new(memory))
    .memory_recall_tokens(1200)
    .build()?;
```

The agent then has `memory_list`, `memory_search`, `memory_write`, `memory_update` and `memory_delete`. Each takes a `scope` argument, `project` by default.

## Limits on the index

The index lists the notes that fit in `with_index_limits(max_notes, max_tokens)`, which defaults to 200 notes and 1500 estimated tokens. The notes that do not fit stay on disk. The agent finds them with `memory_search`.

```rust
let memory = ScopedFileMemory::new(Some(project), Some(global), Some("my-project".into()))
    .with_index_limits(100, 800);
```

For the `bricks` command and the desktop app, see the [Memory](/docs/api-memory) reference and the `[memory]` section of `bricks.toml`.
